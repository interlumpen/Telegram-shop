Telegram Shop — Admin Panel

Quick reference for the panel. Every create/edit/delete here is audit-logged, and the bot's caches are refreshed automatically after a change.

📦 Selling goods (product + stock)

A Product is the listing (name, price, description, category, optional sale). Its sellable units live separately as Stock Items.

  1. Create a Category (if needed).
  2. Create a Product — set name, price, description, category. Sale is optional.
  3. Add Stock Items for that product — this is what buyers actually receive.

Stock Item fields:

  • item — which product this unit belongs to.
  • value — the delivered content (account, key, license text…).
  • is_infinity — off: a limited unit, consumed on purchase (add one row per unit); on: unlimited — the same value is delivered on every purchase and never runs out.

Renaming or deleting a product keeps carts, reviews and purchase history consistent automatically.

🔐 Roles & permissions

A role's permissions is a bitmask: add up the values of the abilities you want. Built-in roles: USER (1), ADMIN, OWNER (all bits). You can only grant permissions you hold yourself.

BitValueGrants
USE1Basic bot access
BROADCAST2Mass messaging
SETTINGS4Maintenance mode
USERS8View / block users, referrals, purchases
CATALOG16Categories, products, stock
ADMINS32Create roles, assign roles
OWNER64Owner-only operations
STATS128Statistics, logs, item search
BALANCE256Top-up / deduct balance
PROMO512Promo-code management

Example: a catalog manager who also sees stats = USE + CATALOG + STATS = 1 + 16 + 128 = 145. Prefer the bot's role menu for a click-to-toggle UI.

🧭 What each section is for

  • Users — balance, role, block status (edits take effect immediately).
  • Roles — permission bitmasks (see the table).
  • Categories / Products / Stock Items — the catalog.
  • Promo Codes — percent / fixed / balance codes, limits, expiry.
  • Purchases / Payments / Operations — read-only financial history.
  • Reviews — 1–5★ product reviews.
  • Audit Logs — read-only record of every admin action.

💡 Good to know

  • Financial tables (purchases, payments, operations) and audit logs are read-only by design.
  • Prices/balances use exact decimals — enter plain numbers (e.g. 199.99).
  • A promo code's discount_type is one of percent, fixed, or balance.
  • Most day-to-day tasks are also available in the bot's in-chat admin menu, which is often quicker for catalog and role edits.
